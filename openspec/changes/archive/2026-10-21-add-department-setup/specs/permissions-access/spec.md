# Дельта: permissions-access

## Purpose

Дозволи на типи заявок і закупівлі та доступ до налаштувань: сторінки адміністратора відкриті лише адміністраторам,
а дозволи працюють однаково для всіх працівників.

## ADDED Requirements

### Requirement: Доступ до налаштувань працівників і відділів

IF користувач без ролі `admin` намагається відкрити список працівників чи налаштування відділів, THEN the system SHALL відмовити в доступі з повідомленням «Недостатньо прав».

#### Scenario: AC-ORG-09 Без ролі адміністратора доступу немає

- **GIVEN** користувач без ролі `admin`
- **WHEN** він намагається відкрити список працівників чи налаштування відділів
- **THEN** доступу немає
- **AND** він бачить повідомлення «Недостатньо прав»

### Requirement: Дозволені типи в профілі працівника

WHEN адміністратор відкриває профіль працівника, the system SHALL показувати серед дозволених йому типів заявок і типів закупівлі для працівника без ролі `admin` типи «Витрата карткою», «Запит на чек», «Рахунок постачальника» і «Самостійна закупівля» лише з відповідним дозволом, а для адміністратора — усі типи незалежно від дозволів.

#### Scenario: AC-ORG-17 З дозволом «Витрата карткою» є серед дозволених

- **GIVEN** працівник без ролі `admin`, якому адміністратор видав дозвіл на «Витрату карткою»
- **WHEN** адміністратор відкриває профіль цього працівника
- **THEN** серед дозволених йому типів заявок є «Витрата карткою»

#### Scenario: AC-ORG-26 Без дозволу «Витрати карткою» серед дозволених немає

- **GIVEN** працівник без ролі `admin` і без дозволу на «Витрату карткою»
- **WHEN** адміністратор відкриває профіль цього працівника
- **THEN** серед дозволених йому типів заявок «Витрати карткою» немає

#### Scenario: AC-ORG-27 Без дозволу лише тип закупівлі «Відділ закупівель»

- **GIVEN** працівник без ролі `admin` і без дозволу «Самостійна закупівля»
- **WHEN** адміністратор відкриває профіль цього працівника
- **THEN** серед дозволених йому типів закупівлі є лише «Відділ закупівель»

#### Scenario: AC-ORG-25 Адміністратору дозвіл на «Витрату карткою» не потрібен

- **GIVEN** адміністратор без дозволу на «Витрату карткою»
- **WHEN** адміністратор відкриває його профіль
- **THEN** серед дозволених йому типів заявок є «Витрата карткою»

### Requirement: Вибір відділу й типу закупівлі адміністратором

WHEN адміністратор заповнює форму заявки «Закупівля» чи «Відшкодування» (у цьому зрізі — заглушка, яка нічого не зберігає), the system SHALL дозволити йому обрати будь-який відділ зі списку всіх відділів незалежно від його відділів, а в закупівлі — будь-який тип закупівлі незалежно від дозволів.

#### Scenario: AC-ORG-22 Адміністратор без відділів обирає будь-який відділ

- **GIVEN** адміністратор без жодного відділу
- **WHEN** він створює заявку «Закупівля» чи «Відшкодування»
- **THEN** він може обрати будь-який відділ зі списку всіх відділів

#### Scenario: AC-ORG-29 Адміністратор-заявник обирає будь-який відділ

- **GIVEN** адміністратор, який є заявником лише відділу «Початкова школа»
- **WHEN** він створює заявку «Закупівля» чи «Відшкодування»
- **THEN** він може обрати будь-який відділ зі списку всіх відділів, зокрема «Офіс»

#### Scenario: AC-ORG-23 Адміністратору дозвіл «Самостійна закупівля» не потрібен

- **GIVEN** адміністратор без дозволу «Самостійна закупівля»
- **WHEN** він створює закупівлю
- **THEN** він може обрати будь-який тип закупівлі, зокрема «Самостійна закупівля»
