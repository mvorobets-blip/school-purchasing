# approval-decision Specification

## Purpose
Схвалювач вирішує лише по заявках свого відділу: бачить свій список для рішення, схвалює чи відхиляє з причиною, а
чужий відділ, власна заявка й заявник без права рішення отримують відмову без змін у заявці.

## Requirements

### Requirement: Список для рішення схвалювача

WHEN схвалювач відкриває свій список для рішення, the system SHALL показувати лише заявки зі статусом «Очікує схвалення» відділів, які він схвалює, крім власних заявок.

#### Scenario: AC-APR-01 У списку лише заявки свого відділу

- **GIVEN** очікують схвалення дві заявки відділу «Початкова школа» й одна заявка відділу «Офіс», схвалювач Марія схвалює лише «Початкова школа»
- **WHEN** Марія відкриває свій список для рішення
- **THEN** вона бачить дві заявки відділу «Початкова школа»
- **AND** заявки відділу «Офіс» у списку немає

### Requirement: Рішення схвалювача

WHEN схвалювач відділу вирішує по заявці цього відділу зі статусом «Очікує схвалення», автор якої — не він, the system SHALL при схваленні дати заявці статус «Схвалено», при відхиленні з причиною — статус «Відхилено», зберегти причину й показувати її на сторінці заявки поруч зі статусом, а відхилення без причини не зберігати й показати повідомлення «Вкажіть причину».

#### Scenario: AC-APR-02 Схвалення заявки свого відділу

- **GIVEN** заявка відділу «Початкова школа» зі статусом «Очікує схвалення», автор — не Марія, Марія схвалює цей відділ
- **WHEN** Марія схвалює її
- **THEN** статус заявки «Схвалено»

#### Scenario: AC-APR-06 Відхилення без причини не збережено

- **GIVEN** схвалювач Марія відхиляє заявку відділу «Початкова школа», не вказавши причину
- **WHEN** вона підтверджує
- **THEN** вона бачить повідомлення «Вкажіть причину»
- **AND** статус заявки лишається «Очікує схвалення»

#### Scenario: AC-APR-07 Відхилення з причиною

- **GIVEN** заявка відділу «Початкова школа» зі статусом «Очікує схвалення», автор — не Марія, Марія схвалює цей відділ
- **WHEN** Марія відхиляє її, вказавши причину «Немає бюджету»
- **THEN** статус заявки «Відхилено»
- **AND** причину «Немає бюджету» збережено й показано на сторінці заявки поруч зі статусом «Відхилено»

### Requirement: Відмова в рішенні без права

IF працівник відкриває заявку відділу, який він не схвалює, чи список для рішення без ролі схвалювача, або намагається схвалити власну заявку, THEN the system SHALL не змінювати статус заявки, а на відкритій сторінці — не показувати даних заявок і вивести «Недостатньо прав».

#### Scenario: AC-APR-03 Заявку чужого відділу не показано

- **GIVEN** заявка відділу «Офіс» зі статусом «Очікує схвалення», Марія схвалює лише «Початкова школа»
- **WHEN** Марія відкриває цю заявку за прямим посиланням
- **THEN** вона бачить повідомлення «Недостатньо прав»
- **AND** даних заявки їй не показано
- **AND** статус заявки лишається «Очікує схвалення»

#### Scenario: AC-APR-04 Заявник не бачить списку для рішення

- **GIVEN** працівник 1 з роллю `requester` увійшов
- **WHEN** він відкриває список для рішення за прямим посиланням
- **THEN** він бачить повідомлення «Недостатньо прав»
- **AND** жодної заявки йому не показано
- **AND** статуси заявок не змінилися

#### Scenario: AC-APR-05 Схвалювач не схвалює власну заявку

- **GIVEN** Петро — схвалювач відділу «Початкова школа» і автор заявки зі статусом «Очікує схвалення»
- **WHEN** він намагається схвалити свою заявку напряму, оминаючи сторінки застосунку
- **THEN** статус заявки лишається «Очікує схвалення»

### Requirement: Автор заявки для схвалювача

WHEN схвалювач відкриває свій список для рішення чи сторінку заявки свого відділу, the system SHALL вказувати автора заявки його ім'ям із профілю, а якщо імені немає — його email, і не показувати ролі, відділів і дозволів автора.

#### Scenario: AC-APR-08 Ім'я автора в списку й на сторінці заявки

- **GIVEN** заявка відділу «Початкова школа» зі статусом «Очікує схвалення», автор — Петро з іменем «Петро» в профілі, Марія схвалює цей відділ
- **WHEN** Марія відкриває свій список для рішення й сторінку цієї заявки
- **THEN** і в списку, і на сторінці заявки вказано автора «Петро»

#### Scenario: AC-APR-09 Email замість імені автора

- **GIVEN** заявка відділу «Початкова школа» зі статусом «Очікує схвалення», автор без імені в профілі з email petro@example.test, Марія схвалює цей відділ
- **WHEN** Марія відкриває свій список для рішення
- **THEN** замість імені автора вказано email petro@example.test

#### Scenario: AC-APR-10 Без інших даних профілю автора

- **GIVEN** заявка відділу «Початкова школа» зі статусом «Очікує схвалення», автор — Петро, Марія схвалює цей відділ
- **WHEN** Марія відкриває свій список для рішення й сторінку цієї заявки
- **THEN** ролі, відділів і дозволів автора там немає
