# 0004. Помічник рядків закупівлі: AI SDK + OpenRouter (безкоштовні моделі) + zod

- Статус: прийнято
- Дата: 2026-11-14
- AC: AC-AI-01, AC-AI-02, AC-AI-03, AC-AI-04, AC-AI-05, AC-AI-06

## Контекст

Зріз 4 (WS10, вимога PM ValiaBihun/2026-quitcode-dream-team#71) додає у форму нової закупівлі помічника: працівник
вставляє вільний опис покупки, а AI пропонує один рядок (назва, мета, кількість, ціна); працівник перевіряє рядок і сам
подає закупівлю. Обмеження:

- Next.js 16.4 на Vercel Hobby; Server Action — один виклик моделі, без агентного циклу.
- Модель — безкоштовна через OpenRouter, ключ — власний. Ліміт безкоштовних моделей — 20 запитів/хв і 50/день на
  акаунт; його ділять усі користувачі застосунку й приймання PM (AC-AI-05 «денний ліміт вичерпано»). Безкоштовні моделі
  з'являються й зникають.
- Безкоштовні ендпоінти можуть зберігати запити → лише синтетичні дані (`*@example.test`, вигадані покупки).
- Відповідь моделі недетермінована, а CI має бути без мережі й без секретів; 15 секунд — межа очікування (AC-AI-04).

## Рішення

- Нові залежності (точні версії, як у наборі курсу `koldovsky/2026-quitcode-10-ai-features-hw/materials/ai-feature/`):
  `ai@7.0.162`, `@openrouter/ai-sdk-provider@3.1.0`, `zod@4.6.7`, `server-only@0.0.1`.
- Виклик — `generateText` + `Output.object({ schema })` (AI SDK 7). Схема zod має стан відповіді моделі (рядок,
  не про закупівлю, вказівки в описі); невідоме поле — `null`. Відповідь не за схемою — збій (AC-AI-04), а не «майже
  рядок».
- Ключ `OPENROUTER_API_KEY` читає лише `src/lib/ai/openrouter.ts` з `import "server-only"`; без `NEXT_PUBLIC_`; чиста
  функція пропозиції отримує модель параметром (тести — `MockLanguageModelV4`).
- Ланцюжок моделей — лише `:free` (`src/lib/ai/models.ts` з набору); `maxRetries: 0`; таймаут 15 с.
  Порядок — за живим eval: Gemma першою (швидка; правопис назви — промпт line-v3), Nemotron — запасна (16.11 не
  відповіла за 15 с). Зміна порядку чи промпту — лише після живого прогону `npm run eval`.
- Правила, які можна перевірити кодом (кількість — ціле від 1, ціна — від 0; вказівки в описі), — у коді на сервері
  після (і для ін'єкції — до) відповіді моделі; модель лише пропонує.
- Людина в контурі: Server Action пропозиції нічого не пише в базу й перевіряє користувача до виклику моделі; запис —
  наявне подання закупівлі (`submitPurchase` → `private.submit_purchase`) після дії людини.
- Якість: 10 golden cases PM (#70) — офлайн-реплей записаних відповідей у `npm test` (CI); живий прогін — `npm run eval`
  вручну, зі звітом частки успіху за моделлю в `evals/reports/`. Назву й мету golden cases PM перевіряє правилом
  «містить» — кодом, без LLM-судді (менше запитів з денного ліміту).

## Розглянуті варіанти

- Claude Agent SDK у функції Vercel — ні: підпроцес Claude Code (~320–342 МБ) не вміщується в пакет функції Vercel
  (до 250 МБ), і потрібен один виклик моделі, а не агент.
- Пакет `openai` з `baseURL` OpenRouter або `@openrouter/sdk` — ні: немає валідації схемою з типізованими помилками й
  тестових моделей в одному API.
- `openrouter/free` (випадкова безкоштовна модель) — ні: результат golden cases не відтворюється.
- LLM-суддя для назви й мети (як у наборі) — ні: правило PM («назва містить «папір»») перевіряється кодом точно, а суддя
  подвоїв би запити з ліміту, спільного з прийманням PM.
- Платний ключ — ні: курс використовує безкоштовні моделі; перехід — заміна однієї фабрики в `src/lib/ai/models.ts`.

## Наслідки

- **Ризик: один користувач може вичерпати спільний денний ліміт** (незалежне рев'ю PR 76). Безкоштовний ліміт
  OpenRouter — 50 запитів на добу UTC на акаунт застосунку, спільний для всіх працівників і приймання PM. Кнопка
  неактивна під час очікування (AC-AI-03), повторів немає (`maxRetries: 0`), вказівки й порожній опис модель не
  витрачають, але обмеження «N запитів на людину за добу» немає: AC PM його не вимагають, а сам стан «ліміт вичерпано»
  обробляє AC-AI-05 («The assistant is unavailable today. Fill in the lines manually», форма працює вручну). Якщо
  помічник вийде за межі навчального проєкту — лічильник на людину в базі (таблиця з RLS, перевірка в дії до виклику
  моделі) або платний ключ із бюджетом; рішення — новим ADR.

- Простіше: провайдера й модель міняємо в одному файлі; CI не залежить від мережі й ліміту.
- Складніше: безкоштовна модель може зникнути або впертися в ліміт — людина бачить повідомлення AC-AI-04 / AC-AI-05 і
  заповнює форму вручну. Ланцюжок перевіряємо `npm run ai:models` перед роботою.
- Записи `tests/fixtures/golden/recorded.json` оновлюємо (`RECORD=1 npm run eval`), коли змінюється промпт
  (`LINE_PROMPT_VERSION`) або схема.
